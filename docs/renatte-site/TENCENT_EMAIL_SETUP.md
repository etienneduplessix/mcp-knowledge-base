# 腾讯云企业邮箱配置指南

## 概述

本指南详细说明如何配置腾讯云企业邮箱，用于接收网站咨询表单提交的邮件通知。

## 腾讯云企业邮箱优势

- ✅ 专业企业形象（使用企业域名邮箱）
- ✅ 更高的邮件送达率
- ✅ 更好的反垃圾邮件保护
- ✅ 更大的邮箱容量
- ✅ 更稳定的服务

## 配置步骤

### 第一步：注册腾讯云企业邮箱

1. 访问 [腾讯云企业邮箱](https://exmail.qq.com/)
2. 点击"免费开通"
3. 选择"企业邮箱标准版"或"专业版"
4. 填写企业信息并提交审核

### 第二步：域名配置

#### 1. 添加域名
在腾讯云企业邮箱管理后台添加您的域名：`renatte.com`

#### 2. 配置DNS记录

根据腾讯云提供的DNS记录，在您的域名管理后台添加以下记录：

**MX记录（邮件交换记录）：**
```
主机记录：@
记录类型：MX
记录值：mxbiz1.qq.com
优先级：5

主机记录：@
记录类型：MX
记录值：mxbiz2.qq.com
优先级：10
```

**TXT记录（SPF记录，防止邮件被标记为垃圾邮件）：**
```
主机记录：@
记录类型：TXT
记录值：v=spf1 include:spf.mail.qq.com ~all
```

**CNAME记录（可选，用于邮箱登录）：**
```
主机记录：mail
记录类型：CNAME
记录值：exmail.qq.com
```

### 第三步：创建邮箱账号

1. 登录腾讯云企业邮箱管理后台
2. 进入"通讯录" → "成员管理"
3. 点击"添加成员"
4. 创建邮箱账号：`info@renatte.com`
5. 设置密码并保存

### 第四步：开启SMTP服务

1. 登录邮箱网页版：`https://exmail.qq.com/login`
2. 使用 `info@renatte.com` 登录
3. 进入"设置" → "客户端设置"
4. 开启"客户端授权码"
5. 复制生成的授权码（注意：不是邮箱密码）

## 环境变量配置

创建 `.env` 文件：

```env
# 腾讯云企业邮箱配置
EMAIL_HOST=smtp.exmail.qq.com
EMAIL_PORT=465
EMAIL_USER=info@renatte.com
EMAIL_PASS=your-client-authorization-code
PORT=3000
```

**重要说明：**
- `EMAIL_PASS` 应该是**客户端授权码**，不是邮箱登录密码
- 授权码在邮箱设置 → 客户端设置中获取
- 如果忘记授权码，可以重新生成

## 腾讯云企业邮箱SMTP设置

### 服务器信息
- **SMTP服务器**：`smtp.exmail.qq.com`
- **端口**：`465`（SSL加密）

### 认证信息
- **用户名**：完整的邮箱地址，如 `info@renatte.com`
- **密码**：客户端授权码

## 常见问题

### Q: 邮件发送失败，提示认证错误
A:
1. 确认使用的是**客户端授权码**，不是邮箱密码
2. 检查邮箱地址是否正确
3. 确认SMTP服务已开启
4. 检查授权码是否过期，重新生成

### Q: 邮件被标记为垃圾邮件
A:
1. 确认已配置SPF记录
2. 检查邮件内容是否包含敏感词汇
3. 添加DKIM记录（可选）
4. 将发件人添加到通讯录

### Q: 无法连接到SMTP服务器
A:
1. 检查防火墙设置，确保端口465开放
2. 确认服务器能够访问外网
3. 检查DNS解析是否正常
4. 尝试使用端口587（STARTTLS）

### Q: 客户端授权码在哪里获取
A:
1. 登录腾讯云企业邮箱网页版
2. 点击右上角头像 → "设置"
3. 选择"客户端设置"
4. 点击"开启客户端授权码"
5. 按提示操作获取授权码

## 安全建议

### 1. 定期更换授权码
建议每3-6个月更换一次客户端授权码。

### 2. 限制IP访问
在腾讯云企业邮箱管理后台，可以设置允许使用SMTP服务的IP地址。

### 3. 监控邮件发送
定期检查邮件发送日志，发现异常及时处理。

### 4. 使用专用邮箱
建议使用专门的邮箱账号（如 `info@renatte.com`）接收咨询，不要用于其他用途。

## 高级配置

### 1. 多邮箱接收
如果需要多个邮箱同时接收咨询邮件：

```javascript
const mailOptions = {
  from: process.env.EMAIL_USER,
  to: 'info@renatte.com, sales@renatte.com, support@renatte.com',
  subject: `新的咨询 - ${name}`,
  // ...
};
```

### 2. 邮件抄送
```javascript
const mailOptions = {
  from: process.env.EMAIL_USER,
  to: 'info@renatte.com',

  // ...
};
```

### 3. 邮件密送
```javascript
const mailOptions = {

  to: 'info@renatte.com',

  // ...
};
```
